# AI 360 보고 및 시연 시나리오 가이드

> 발표자는 화면 우측 상단 **`[🎯 발표·시연 가이드]`** 버튼을 눌러 각 단계로 원클릭 이동하며 본 대본 순서대로 시연할 수 있습니다.

---

## 1. 오프닝: 구축 배경과 핵심 가치 (30초)

- **화면:** `E. 총괄 관리자` → `1. 통합 대시보드`
- **발표 포인트:**
  - "산업통상부와 6개 소속기관(총 1,000명 샘플 기준)의 오프라인 집합교육 운영과 AI 역량 진단을 하나로 묶은 전주기 관리 플랫폼 **「AI 360」** 프로토타입입니다."
  - "가장 큰 특징은 **교육 담당자가 과정 한 건만 등록하면 계획서 작성부터 QR 출결, 수료 집계, 만족도 조사, 공문서 결과보고서까지 한 흐름으로 자동화**된다는 점입니다."
  - "대시보드 막대 차트를 클릭하면 `전체 기관 → 소속기관(산업통상부) → 실·국(기획조정실) → 부서` 순으로 즉시 드릴다운됩니다."

---

## 2. 핵심 시연 ①: 집합교육 등록 한 번으로 전주기 자동화 (3분)

### Step 2-1. 교육 등록 및 산출물 3종 즉시 자동 생성
1. 좌측 메뉴 **`2. 집합교육 관리 (자동화)`** 클릭 → 우측 상단 **`[+ 신규 집합교육 등록]`** 클릭
2. 모달 우측 상단 **`[✨ 시연용 샘플값 자동 입력]`** 클릭 (시작·종료 시각에 따른 **이수시간 4시간 자동 계산** 확인)
3. 하단 **`[교육 등록 및 QR·계획서·안내문 즉시 생성]`** 클릭
4. 생성 즉시 다음 탭을 차례대로 확인:
   - **`① QR 3종 · 스캔 시뮬레이션`**: 신청 QR / 현장 출석 QR / 만족도 QR 자동 생성 확인, **`[🖨️ A4 게시물 인쇄]`** 시연
   - **`② 교육 계획서 (A4)`**: 추진배경·개요·커리큘럼·신청 QR이 공문서 양식으로 자동 작성됨 확인, 문구 실시간 수정 및 **`[🖨️ 계획서 A4 인쇄 / PDF 저장]`** 확인
   - **`③ 안내문 · 알림 발송`**: 메신저용·이메일용 안내 문구와 대상자 명단 엑셀 다운로드 확인 후 **`[📣 안내 발송 실행]`** 클릭 → 교육 상태가 즉시 `신청 중`으로 전환되며 교육생 알림함에 도착!

### Step 2-2. 휴대폰 없이 현장 QR 스캔 시뮬레이션 (신청 → 출석·수료 → 만족도)
1. 좌측 교육 목록에서 당일 진행 과정인 **`산업 AI·제조 AX 정책 동향 및 현장 적용 세미나 (CRS-008)`** 선택
2. 출석 QR 아래 **`[📱 스캔 시뮬레이션 실행]`** 클릭 → 스마트폰 화면 모달 오픈
3. 시연 사용자로 `박선하 사무관`(사전 신청자) 확인 후 **`[📍 현장 출석 · 수료 인증하기]`** 클릭 → 즉시 출석 시각 기록 및 수료 처리 완료!
4. 스캔 시연 사용자를 `염기민 주무관`(미신청자)으로 변경 후 출석 버튼 클릭 → **`[현장 신청 자동 처리] 출석·수료 완료`** 확인 (체크박스 해제 시 미신청자 차단도 시연 가능)
5. 상단 탭 **`만족도 QR`** 전환 → 5문항 척도 및 자유의견 입력 후 **`[만족도 응답 제출하기]`** 클릭 → 배경의 관리자 집계 숫자가 즉시 올라가는 것 확인!
6. **`④ 신청·수료 집계 & 보정`** 탭에서 `신청 후 미출석자` 선택 → 사유 입력 후 **`[수동 수료 처리]`** 클릭 시연

### Step 2-3. 교육 결과보고서 자동 작성 및 현장 사진 배치
1. **`⑥ 결과보고서 (사진·A4)`** 탭 클릭
2. 신청률·수료율·소속별/직급별 현황 및 문항별 만족도 평균이 공문서에 자동 기입된 모습 확인
3. **`[+ 샘플 일러스트 추가]`** 또는 실제 이미지 파일 업로드(최대 4장) → 우측 A4 미리보기 하단에 즉시 배치 확인 후 **`[✓ 결과보고 완료 확정]`** 클릭

---

## 3. 핵심 시연 ②: 교육생 역량 진단 → 맞춤 교육 추천 → 성장 기록 (2분)

1. 상단 헤더 **`시연 사용자 전환`** → **`A. 교육생 (본인)`** (`박선하 사무관`) 선택
2. **`나의 AI 대시보드`**에서 종합 점수 반원 게이지(75.0점, 심화), 상·하반기 7축 레이더 비교, 회차별 성장 그래프 확인
3. 우측 **`맞춤형 추천 집합교육`**에서 진단 보완 영역(`프롬프트 설계`, `데이터 활용`)과 매핑된 추천 과정 및 추천 사유 확인 후 **`[바로 신청]`** 클릭
4. 상단 세부 인물을 `염기민` 또는 `[진단미응답]` 인물로 바꾸거나 좌측 **`AI 역량 진단`** 메뉴에서 7문항 자가진단 제출 즉시 레이더·강점 2개·보완 2개가 갱신되는 흐름 시연

---

## 4. 핵심 시연 ③: 5단계 계층형 권한 범위 차이와 독려 (2분)

1. 상단 **`시연 사용자 전환`** → **`B. 부서 담당자` → `C. 실·국 담당자` → `D. 소속기관 담당자`** 순차 전환
2. **핵심 강조 포인트:**
   - "실·국 담당자(기획조정실 차태빈 과장)는 기획조정실 산하 4개 부서만 비교·드릴다운할 수 있으며, 다른 실·국 데이터는 절대 조회할 수 없고 오직 **비교용 전 기관 전체 평균선(붉은 점선)**만 제공됩니다."
   - 상단 **`[관리 화면 | 나의 화면(교육생)]`** 토글을 눌러 담당자 본인도 교육생으로서 자기 역량과 교육을 관리할 수 있음을 시연합니다.
3. 좌측 **`미이수 · 미응답 독려`** 메뉴 클릭 → `진단 미응답자` 명단 엑셀 다운로드, 독려 문구 복사, **`[✓ 독려 발송 실행 및 이력 기록]`** 클릭 시 하단 독려 이력 테이블에 즉시 누적 확인

---

## 5. 클로징: 명단 엑셀 검증 · 담당자 지정 · 기관장 1페이지 보고 (1분 30초)

1. 상단 **`E. 총괄 관리자`** 복귀
2. **`4. 명단 관리 (엑셀)`**: **`[📥 명단양식 다운로드]`** 및 **`[✨ 시연용 샘플 파일(신규 3·변경 2·오류 1) 즉시 검증 체험]`** 클릭 → 컬럼 검증·오류 행 분리·미리보기 후 **`[➕ 추가·갱신 반영]`** 시연
3. **`5. 담당자 지정`**: `"샘플 자동지정"` 배지 확인, 특정 부서 담당자 **`[해제]`** 클릭 시 상단에 **`⚠️ 담당자 미지정 단위 경고`** 배너 즉시 점등 확인
4. **`6. 성과 분석 · 보고`**: **교육 미수료군 vs 1과정 수료군 vs 2과정 이상 수료군의 상·하반기 역량 상승폭 차이**를 제시하며 교육 효과를 데이터로 입증하고, **`[🖨️ 기관장 보고용 1페이지 요약 인쇄 / PDF]`** 버튼으로 마무리!
5. 시연 종료 후 상단 **`[↺ 샘플 데이터 초기화]`** 클릭으로 다음 시연을 위해 원상 복구.
