# AI 360 (AI Competency 360)

> **산업통상부 AI 역량 전주기 관리 플랫폼 — 보고 및 시연용 웹 프로토타입 (보강판 v3 반영)**  
> **핵심 슬로건:** *"AI 역량의 시작부터 성장까지, AI 360°"*

---

## 1. 프로젝트 구축 목적

1. **[목적 1순위] 집합교육(오프라인 교육) 운영 전주기 자동화**
   - 교육 담당자의 반복 행정업무(`교육 등록 → QR 3종 생성 → 계획서 작성 → 안내 발송 → 신청 집계 → 현장 QR 출석 확인 → 수료 집계 → 만족도 조사 → 결과보고서 작성`)를 **단 한 번의 과정 등록**으로 자동화합니다.
2. **[목적 2순위] AI 역량 진단 — 맞춤 교육 추천 — 성과 분석 환류**
   - 연 1~2회 실시하는 **7개 영역 AI 역량 자가진단** 결과를 개인별 보완 교육 추천과 직급별 리더십 과정에 자동 연결하고, 교육 수료 전·후 역량 성장 효과를 정량 입증합니다.

---

## 2. 실행 방법 (별도 서버·빌드 불필요)

본 프로토타입은 순수 `HTML5 + CSS3 + Vanilla JavaScript` 아키텍처로 구현되어 별도 백엔드 서버 설치 없이 브라우저에서 즉시 동작합니다.

- **방법 A (탐색기에서 바로 실행):** 프로젝트 루트의 `index.html` 파일을 크롬(Chrome) 또는 엣지(Edge) 브라우저로 바로 엽니다.
- **방법 B (로컬 정적 웹서버 실행):**
  ```powershell
  python -m http.server 8080
  # 브라우저에서 http://localhost:8080 접속
  ```
- 모든 변경 데이터(신규 과정 등록, 교육 신청, QR 출석·만족도 응답, 역량 진단 제출, 명단 엑셀 업로드, 담당자 변경 등)는 브라우저 `localStorage`에 즉시 저장되어 5단계 권한 화면 전체에 실시간 반영됩니다.
- 우측 상단 **`[↺ 샘플 데이터 초기화]`** 버튼을 클릭하면 언제든 최초 시연 상태(고정 시드 샘플 데이터)로 복원됩니다.

## 4. 5단계 계층형 권한 및 시연 페르소나

상단 헤더의 **「시연 사용자 전환」** 드롭다운으로 로그인 없이 즉시 권한별 화면과 조회 범위 차이를 비교 시연할 수 있습니다. 또한 담당자(B~E) 선택 시 **「관리 화면 ↔ 나의 화면(교육생)」** 토글을 지원합니다.

| 권한 구분 | 기본 시연 인물 | 조회 가능 범위 | 핵심 시연 포인트 |
| :--- | :--- | :--- | :--- |
| **A. 교육생** | 박선하 사무관 (정보관리담당관) | 본인 데이터만 | 나의 AI 대시보드, 알림함, QR 출석·만족도, 7문항 진단, 성장 기록 |
| **B. 부서 담당자** | 김진솔 과장 (정보관리담당관) | 소속 부서 (타 부서 비공개) | 부서 7대 KPI, 직급별 비교 + 전체 평균선, 미응답·미이수 독려 |
| **C. 실·국 담당자** | 차태빈 과장 (기획조정실) | 소속 실·국 산하 부서 드릴다운 | 부서별 비교 막대 + 전체 평균선, 구성원 검색·필터, 독려 기록 |
| **D. 소속기관 담당자** | 성현연 과장 (산업통상부) | 소속기관 산하 실·국·부서 드릴다운 | 실·국별 비교, 우리 기관 vs 전체 평균 7축 레이더 비교 |
| **E. 총괄 관리자** | 정형석 사무관 (교육 총괄) | 전 기관 전체 (1,000명) | 교육 등록·QR·계획서·결과보고 자동화, 진단 회차, 명단·담당자·기관장 보고 |

---

## 5. 유의사항

- 모든 화면 상단에 **`시연용 샘플 데이터`** 배지가 상시 표시됩니다.
- 수록된 1,000명의 인원 명단 및 교육·진단 수치는 시연 목적으로 고정 시드에서 생성된 가상 샘플 데이터이며 실존 인물 및 실제 기관 실적과 무관합니다.
